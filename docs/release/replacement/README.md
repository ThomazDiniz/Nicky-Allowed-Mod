# Nicky Allowed — Replaced Centipedes

Alpha {{VERSION}} — replacement variant.

This complete package contains {{PAYLOAD_COUNT}} mod files. Reviewed parasite appearances are replaced with alternative models; existing scenery removals and blood particle substitutions are retained. Long-arm Centipede C1030/C1040 is preserved. See CHANGES-AND-TESTS.md for the exact completed replacement coverage.

Install [Sekiro Mod Engine](https://www.nexusmods.com/sekiro/mods/6), close the game, and copy this package's `mods` folder beside `sekiro.exe`. Configure `useModOverrideDirectory=1` and `modOverrideDirectory="\mods"` in `modengine.ini`.

Choose either the invisible or replacement variant. Do not combine their files. When switching, back up your current mod folder and replace this mod's complete payload using its manifest; preserve unrelated mods. Both variants overwrite the same game packages.
